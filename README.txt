GRASS ON BUGS — interfaz inicial
1. Descomprime Grass_on_Bugs.zip.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html en el navegador o usa Live Server.
4. No muevas la carpeta assets: contiene el logo.

La vista previa de imágenes y los consejos funcionan. La identificación automática, la base de datos y el backend aún no están conectados. Las tarjetas de insectos son contenido de ejemplo.
