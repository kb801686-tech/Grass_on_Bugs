# 🌱 Grass on Bugs

## Descripción del proyecto

Grass on Bugs es un proyecto enfocado en la identificación y consulta de información sobre insectos que se encuentran en entornos naturales, especialmente cerca de plantas y floras.

La idea principal es ofrecer una herramienta sencilla que permita conocer más sobre los insectos mediante fotografías y consultar información útil sobre ellos.

## Objetivo

Desarrollar una aplicación web que facilite el reconocimiento de insectos y proporcione información sobre sus características, comportamiento y relación con el entorno natural.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- MySQL

## Estado actual del proyecto

Actualmente se está trabajando en la estructura principal de la aplicación, la configuración del entorno backend y la preparación de la base de datos.

El proyecto continúa en desarrollo y se irán incorporando nuevas funcionalidades conforme avance su construcción.

## Funcionalidades propuestas

- Captura o selección de fotografías de insectos.
- Identificación de insectos mediante herramientas de inteligencia artificial.
- Consulta de información sobre las especies identificadas.
- Información sobre insectos beneficiosos y perjudiciales.
- Recomendaciones básicas para el manejo de insectos.

## Instalación

1. Descargar o clonar el repositorio.
2. Instalar las dependencias del backend con `npm install`.
3. Configurar la conexión con la base de datos MySQL.
4. Ejecutar el servidor desde la carpeta del backend.
